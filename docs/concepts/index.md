# Concepts

Background for deciding whether and how to rely on Krishiv. [Compatibility](compatibility.md) gives the support status of each
surface (file formats, object stores, SQL, Spark Connect); [Known differences](known-differences.md) describes the places where behaviour
deliberately differs from Spark; [API stability](stability.md) says which interfaces may still change. Read these
before a migration; the how-to steps are in the [guides](../guides/index.md).
