Spark golden row order-by#7 now matches: an ORDER BY over an outer column inside a scalar subquery raises CORRELATED_REFERENCE.
A scalar subquery is named after the outer columns of every CTE it defines, an unused one included (`scalarsubquery(id)`), as Spark does (goldens cte-nested 3, cte-nonlegacy 3).
A map lookup written as a dotted path (`col1.field`) is named by its last part, so a later select item can read it as a lateral column alias (golden alias-resolution-edge-cases 6).
