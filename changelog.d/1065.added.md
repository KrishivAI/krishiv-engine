The console UI source is now a pnpm workspace: the shared component and token package `@krishiv/ui` (`ui/packages/ui`, with the unified product design tokens) and the console app (`ui/apps/console`). The served console is unchanged.

`@krishiv/ui` has its first slice components (button, field, select, callout, badge, dialog, tabs, menu, a sortable and virtualised grid shell, and empty, error and loading states), each on a page of a dev-only gallery that is checked under the console's content security policy and with axe.
