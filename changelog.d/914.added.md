Spark Connect `Catalog` relations: all 36 operations of `spark.catalog` (databases, tables, columns, functions, views, partitions, caching, create and drop) run over Connect and answer with the rows Spark returns; the session catalog API gains `drop_table`, `drop_view`, `create_database`, `drop_database`, `truncate_table`, `analyze_table`, `list_partitions`, `list_views`, `get_table_properties` and `get_create_table_string`.
