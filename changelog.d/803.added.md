SQL access control in Rust library sessions: `GRANT`, `REVOKE`, `SHOW GRANTS` and roles, checked per column a query reads (`krishiv.access.provider=grants`; `krishiv server` does not apply object grants). In server mode, outbound object-store and catalog requests reach only public addresses unless an admin allows more (`krishiv.io.egress.*`), and catalogs are declared at startup with `krishiv.catalog.<name>.*`.
