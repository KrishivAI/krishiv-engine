A vector top-k query with a literal query vector no longer copies the vector for every row: `array(...)` of literals is folded to one literal when it is an argument of a `vector_*` function.
A user-defined type (Spark's `UserDefinedType`, including PySpark's Python-only ones) is a column type: it keeps its class names through Spark Connect, `krishiv.plan.v1` and Parquet, and runs as its storage type in `ORDER BY`, `GROUP BY`, `=` and joins. Spark Connect refuses a UDT with a missing field as Spark does, except that a JVM UDT also needs its `sql_type`.
