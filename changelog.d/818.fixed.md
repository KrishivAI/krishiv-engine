The `vector_*` functions (`vector_inner_product`, `vector_l2_distance`, `vector_cosine_similarity`, `vector_norm`, `vector_normalize`) match Spark 4.2.0 bit for bit: sums run in blocks of 8 as Spark does (a plain fold differed from 8 dimensions up), `vector_norm(v, float('inf'))` skips a NaN element, a NULL element no longer hides a dimension mismatch, and cosine similarity and normalize give NULL below `Float.MIN_NORMAL`. 768-dimension goldens come from a real Spark 4.2.0 run.
