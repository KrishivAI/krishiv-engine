Flight SQL catalog metadata: `GetCatalogs`, `GetDbSchemas`, `GetTables` (with table schemas), `GetTableTypes` and the key commands list what `SHOW` would show the caller, under `krishiv.flightSql.metadataTimeout`; `SetSessionOptions`, `GetSessionOptions` and `CloseSession` set the current catalog, schema and session settings; `GetXdbcTypeInfo` lists the Spark column types with their XDBC codes.
