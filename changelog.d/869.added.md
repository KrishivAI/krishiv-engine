A declared Iceberg REST catalog can use `auth = delegated`: each user reaches the catalog as themselves, by an RFC 8693 token exchange of their OIDC token or signed assertion (`delegation = exchange`, the default) or by forwarding a token whose audience names the catalog (`delegation = forward`). A session without a user token gets `KRISHIV_CATALOG_DELEGATION_UNAVAILABLE`, never the server's identity; exchanges are limited by `krishiv.catalog.delegation.maxExchangesPerMinute` and `maxDistinctExchangesPerMinute`.
