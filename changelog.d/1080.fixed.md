`spark.conf.get` (Spark Connect, the embedded session and SQL `SET key`) of an unset Spark SQL config that Krishiv does not use now answers Spark's default instead of `SQL_CONF_NOT_FOUND` (for example `spark.sql.execution.arrow.pyspark.enabled`), and `spark.conf.isModifiable` answers as Spark does.
`spark.sql.legacy.execution.pythonUDF.pandas.conversion.enabled` can be set, and Arrow-optimized Python UDFs then convert their values through pandas as Spark's legacy path does.
