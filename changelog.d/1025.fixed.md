`CREATE TABLE ... USING delta COMMENT '...'` is refused by name instead of dropping the comment. A MERGE `SET` column takes the target's qualifiers as delta-spark does. A padded or unknown session time zone set through the builder, `--conf` or startup settings is refused with `INVALID_CONF_VALUE.TIME_ZONE`, as Spark does. A SQL function argument the body never reads is still checked against the GROUP BY (`MISSING_AGGREGATION`). A vended-credential refresh that narrows the prefix below a scope's root still serves that scope.
