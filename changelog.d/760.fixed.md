`spark.read.csv(path, schema=...)` (and `DataFrameReader.schema()`) no longer ignores the schema and reads every column as a string: until reads take a user schema it fails with `KRISHIV_UNSUPPORTED_FEATURE`; declare the columns with `CREATE TEMPORARY VIEW v (<columns>) USING csv OPTIONS (path '...')` (KN-1, PY-030). Reading CSV with `inferSchema` is about 6x faster: inference runs in parallel and is done once per file version, so later actions do not read the file twice (10M-row, 509 MB CSV on 12 cores: inference 13.0 s to 2.1 s, a count after it 16.6 s to 2.7 s) (PY-012). Parsing a CSV line costs about half as much: lines without quote characters are split at the separator, and UTF-8 lines are not copied. This matters most for a gzip file, which is read on one core (35M-row, 227 MB `.csv.gz`, a count and a filtered average: 73 s to 36-41 s; Spark 4.2.0 takes 47-50 s on the same machine) (PY-013).
