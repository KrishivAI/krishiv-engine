`spark.read.csv(path, schema=...)` (and `DataFrameReader.schema()`) no longer ignores the schema and reads every column as a string: until reads take a user schema it fails with `KRISHIV_UNSUPPORTED_FEATURE`; declare the columns with `CREATE TEMPORARY VIEW v (<columns>) USING csv OPTIONS (path '...')`. Reading CSV with `inferSchema` is about 6x faster: inference runs in parallel and is done once per file version, so later actions do not read the file twice (10M-row, 509 MB CSV on 12 cores: inference 13.0 s to 2.1 s, a count after it 16.6 s to 2.7 s).
