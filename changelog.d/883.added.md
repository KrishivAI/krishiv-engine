`INSERT OVERWRITE` on Iceberg tables follows Iceberg's rules: a static overwrite replaces the rows a filter matches (a data file only partly matched is refused with `KRISHIV_ICEBERG_OVERWRITE_PARTIAL_FILE`), a dynamic overwrite replaces the partitions it writes, and conflict validation runs only under the `isolation-level` write option. It becomes available once Krishiv can write through an Iceberg catalog.
