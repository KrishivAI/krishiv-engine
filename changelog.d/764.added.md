The Python `pyspark.sql.functions` names that were missing now exist with PySpark's signatures: the generators (`explode`, `posexplode`, `inline`, `stack`, ...), the higher-order functions (`transform`, `filter`, `aggregate`, `exists`, `forall`, `zip_with`, `map_filter`, `transform_keys`/`transform_values`, `array_sort` with a comparator, ... take Python lambdas), `max_by`/`min_by`, `any_value`, `array_agg`, `every`/`some`, `chr`, `power`, `negate`, `like`/`ilike`/`rlike`, the CSV and XML functions with options, the sort-order, bitmap, sketch and `xpath` families, `broadcast` and `call_udf`; `Column` gains `**`. A function the engine lacks fails with a clear `NotImplementedError` or the analyzer's unsupported-function error instead of an `AttributeError`.
