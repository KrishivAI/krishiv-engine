The optimizer can group an aggregate by a fact table's join key and join the dimension's columns above it, when the dimension's key is known to be unique. With `krishiv.optimizer.discoverKeys` the session proves the key of plain Parquet files by reading the key columns once (bounded by `krishiv.optimizer.discoverKeys.timeout`) and caches the answer per file version. Both `krishiv.optimizer.payloadAboveAggregate` and `krishiv.optimizer.discoverKeys` are off by default.
