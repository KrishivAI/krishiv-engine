Changing a static Spark SQL config at runtime (`spark.conf.set`, `spark.conf.unset`, SQL `SET` or `RESET` of `spark.sql.warehouse.dir`, `spark.sql.globalTempDatabase` and the other static keys) now fails with `CANNOT_MODIFY_STATIC_CONFIG`, and of a Spark core config (`spark.executor.memory`, `spark.ui.port`) with `CANNOT_MODIFY_CONFIG`, as in Spark; set them when the session is built (`SparkSession.builder.config`, `Session::builder().config`).
