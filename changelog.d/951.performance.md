Queries that filter a dimension joined above an outer join now reduce the outer join's preserved side first: TPC-DS q40 uses about 4 times fewer CPU cycles (0.23x) and q80 0.76x at scale factor 10, results unchanged. Joins against a tiny table on one integer key probe it by direct index: q62 0.86x and q99 0.81x CPU cycles at scale factor 10.
A runtime join filter whose keys are a few integers over a short range tests each row with one bit lookup instead of a hash set: TPC-DS q34 0.89x, q73 0.90x, q02 0.85x and q95 0.89x CPU instructions at scale factor 10, no query slower.
