Python UDFs over Spark Connect: `spark.udf.register` and inline `udf(...)` calls (scalar eval types 100, 101, 200 and 250) run on the server's isolated Python worker pool, in workers of the calling session only. Client code needs `Usage` on `System("udf")` (admin in server mode) before anything is registered or any worker starts; a UDF that raises reaches the client as `PYTHON_EXCEPTION` (PySpark's `PythonException`), and releasing a session stops its workers.
