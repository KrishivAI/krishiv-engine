Once no query has run for a second, every engine thread returns the memory it freed to the operating system, so an embedded or server process no longer holds its last query's peak while idle (TPC-DS SF10 in one process: peak memory 2.35x DuckDB's before, 1.07x after; a Python session's idle memory about 570 to 205 MiB). `krishiv.memory.releaseAtQueryEnd` (default on) turns it off.
