Delta tables can be written: `INSERT INTO` and `INSERT OVERWRITE` (static and dynamic partitions), CTAS and `CREATE TABLE .. USING delta`, `df.write.format("delta").save` with `replaceWhere`, `saveAsTable`, `insertInto` and `writeTo(..).append()`. Each write is one Delta commit with Delta's statistics and metrics, honours `maxRecordsPerFile`, and is checked against the table's features, append-only and NOT NULL columns as delta-spark checks them.
