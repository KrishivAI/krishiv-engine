Delta tables can be used from the session (build feature `delta`): `spark.read.format("delta").load(path)`, `` delta.`path` ``, `CREATE TABLE .. USING delta LOCATION` and the temporary-view form. Writes and DDL on Delta tables are refused by name for now. Snapshots are cached per table root (`krishiv.delta.snapshotCache.maxBytes`, 64 MiB), and a cancelled query stops its Delta work.
