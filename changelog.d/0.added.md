`spark.read.schema(...)` and `schema=` on `spark.read.csv`/`json`/`load` now read the files as the given columns (a `StructType` or a DDL string such as `"id INT, name STRING"`) instead of failing; Spark Connect reads with a schema too, and the Rust `DataFrameReader` gains `schema` and `schema_ddl`. As in Spark, every column reads as nullable and `k=v` partition columns come last, typed by the schema when it names them (KN-1, PY-018, PY-030).
