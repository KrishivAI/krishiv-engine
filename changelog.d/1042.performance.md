ROLLUP and grouping-set queries are faster: eager aggregation now reads a dimension whose only filters are the inferred join-key null checks (TPC-DS q22: about 0.30x CPU cycles), and when the pre-aggregate under an `Expand` does not reduce, each grouping set is merged from its smallest computed parent set instead of expanding every row (TPC-DS q67; config `krishiv.optimizer.rollupFromParent`, on by default).
