Spark Connect plans with `mapInPandas`/`mapInArrow`, `groupBy().applyInPandas`/`applyInArrow` and `cogroup().applyInPandas`/`applyInArrow` now translate into the engine's Python UDF relations (with the same `Usage` on `System("udf")` check as inline UDFs), so `df.schema` and `explain` work, and a grouped or cogrouped map over a nondeterministic UDF fails there with Spark's `INVALID_NON_DETERMINISTIC_EXPRESSIONS`. Running them still fails with `KRISHIV_UDF_NOT_AVAILABLE`: the UDF worker pool cannot run these relations yet.
