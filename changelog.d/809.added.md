`krishiv server` serves the `krishiv.admin.v1` control API on the admin listener over gRPC and REST (`/api/admin/v1`): `GetVersion` and `GetCapabilities`, behind the server's authentication, with `krishiv.server.allowedHosts` for loopback listeners. `GET /api/v1/version` is deprecated in favour of it and, with authentication configured, now needs a credential like `GetVersion` (P3-T066).
