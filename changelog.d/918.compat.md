Reading partitioned files now resolves the partition layout per leaf directory as Spark 4.2.0 does: two base paths raise `CONFLICTING_DIRECTORY_STRUCTURES`, differing partition columns raise `CONFLICTING_PARTITION_COLUMN_NAMES`, files beside partition directories are skipped, and the `ignoreInvalidPartitionPaths` read option and `spark.sql.files.ignoreInvalidPartitionPaths` config are honoured.
