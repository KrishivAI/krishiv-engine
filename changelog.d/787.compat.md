Partition-indexed expressions (`rand`, `randn`, `uniform`, `uuid(seed)`, `monotonically_increasing_id()`, `spark_partition_id()`, TABLESAMPLE and others) inside a `UNION ALL` branch now read the branch's own partition index, as Spark does, and a union of one-partition inputs is one partition (`krishiv.sql.unionOutputPartitioning`, alias of `spark.sql.unionOutputPartitioning`, default on). `randn` now matches Spark's values to the last bit.
