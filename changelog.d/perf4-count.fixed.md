`count()` of a CSV or JSON read no longer decodes values, as Spark: a CSV count counts lines without tokenizing them (unless `multiLine` or `columnPruning=false`), and a JSON `DROPMALFORMED` count drops only records that are not JSON objects (a value of the wrong type no longer lowers the count). A `multiLine` JSON file is read as its first value only, as Spark reads it (rows, count, the corrupt-record text and schema inference); text after that value is no longer returned as further rows.
