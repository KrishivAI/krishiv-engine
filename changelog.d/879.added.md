The Connect server answers the sixteen Spark SQL settings a PySpark client reads when it starts a session or calls `createDataFrame` (`spark.sql.timestampType`, `spark.sql.session.localRelation*` and others) with Spark 4.3's defaults, instead of SQL_CONF_NOT_FOUND.

`COMMENT ON COLUMN table.column IS 'comment' | NULL` (Spark 4.3) sets or clears a column comment.
Spark 4.3 `SHOW TABLES`, `SHOW TABLE EXTENDED` and `SHOW PARTITIONS ... AS JSON` return one `json_metadata` string in Spark's shape.
