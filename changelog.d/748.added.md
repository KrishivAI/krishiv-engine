Workload management: `krishiv.workload.resourceGroups.file` limits concurrency, queueing, per-query memory and scanned bytes per group, routes queries by user, source, tag and statement type, and the lowest-priority query is stopped first when memory runs out; `system.queries` shows each query's `resource_group` and `queued_ns`. Queries can carry request tags and be cancelled by tag (`Session::interrupt_tag`, `EngineRuntime::cancel_by_tag`).
