A query that computes the same CTE several times, each time filtered to a different value of a grouping column, now
computes it once (`krishiv.optimizer.shareLiteralInstances`, on by default): TPC-DS q31 and q64 use about half the CPU
cycles and q75 0.73x at scale factor 10 (laptop). Widening integer casts run up to 49x faster (ClickBench q30 0.52x
cycles), and a Flight SQL query is analysed 3 times instead of 5. `krishiv.optimizer.groupKeyCodeMultiDimension` (off
by default) groups aggregates whose keys come from two or more dimension tables on compact codes: TPC-DS q47 and q57
use about 0.78x the CPU cycles.
