`_metadata.file_path` prints a file under the path as it was read (`s3a://bucket/...` stays `s3a://`, an Azure host as written), and `_metadata.file_name` is the quoted last segment, as in Spark. `input_file_name()`, `input_file_block_start()` and `input_file_block_length()` return the file being read instead of `''` and -1, with Spark's `MULTI_SOURCES_UNSUPPORTED_FOR_EXPRESSION` check.
