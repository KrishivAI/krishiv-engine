Parquet files with the legacy two-level list layout (parquet-mr and Avro writers, such as Spark's own
`examples/src/main/resources/users.parquet`) now read instead of failing with `FAILED_READ_FILE.CANNOT_READ_FILE_FOOTER`.
Files read by path (`spark.read`, `` parquet.`path` ``) now have nullable columns at every depth, as Spark reads them:
an array element, map key or value field, or struct field that the file declares required reads as nullable
(`containsNull = true`). Permanent tables over files are not changed yet.
