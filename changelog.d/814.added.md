A write of NULL into a NOT NULL column now fails with `NOT_NULL_ASSERT_VIOLATION`, as in Spark 4.2 (skipped under `spark.sql.storeAssignmentPolicy=LEGACY`). `krishiv-catalogs` has an embedded SQLite catalog behind the new `sqlite` feature (off by default): a catalog in one file that several processes can share, with the same behaviour as the in-memory one.
