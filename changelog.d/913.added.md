Arrow Flight SQL works with the Arrow JDBC driver end to end: prepared statements advertise each `?` parameter with the type its context gives it (so `setDate`, `setInt` and friends bind), decimal columns report their precision and scale, an update that reports no row count answers 0 instead of being run a second time, and a JDBC or ADBC client may log in with `user=<principal>&password=<token>` (HTTP Basic, Flight SQL only).
