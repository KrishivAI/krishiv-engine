`cargo xtask quarantine --flaky <nextest-log>` fails when a test passed only on a retry and is not listed in `tests/quarantine.toml`, and prints the stanza to add.

`cargo xtask release-check [VERSION]` is a read-only release preflight: the version, the crate versions, the publish list and its dependency order, the changelog, the release workflows and the tag.

`cargo xtask ci-time` reports the PR gate's wall time (median, p90, mean) from `gh run list` data, and `--compare BEFORE AFTER` the change between two saved lists.
