`schema_of_json` infers TIME (Spark 4.3), TIMESTAMP_NTZ and TIMESTAMP under `inferTimestamp` as Spark does, keyed by the session. JSON files infer the TIMESTAMP_NTZ and LEGACY arms and, under `spark.sql.legacy.timeParserPolicy=LEGACY`, read with Spark's legacy patterns and lenient fallback. JSON schema inference (`schema_of_json` and JSON files) under `prefersDecimal` reads strings as decimals, merges decimals as Spark does, and refuses a number with a negative scale (`1e3`) with `NEGATIVE_SCALE_DISALLOWED`. CSV files read dates and timestamps under `spark.sql.legacy.timeParserPolicy=LEGACY` as Spark does (legacy patterns, lenient fallback, no DATE inference); with the fallback off and no `dateFormat`, CSV and JSON dates read strictly as `yyyy-MM-dd`.
