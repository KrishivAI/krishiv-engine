With `spark.sql.files.ignoreCorruptFiles=true`, a Parquet file whose footer cannot be read is skipped, as in Spark, instead of failing the query with `FAILED_READ_FILE.CANNOT_READ_FILE_FOOTER` at planning time. Schema inference follows Spark 4.2.0: under `mergeSchema` the file leaves the merge; without it a skipped first file gives `UNABLE_TO_INFER_SCHEMA`.
