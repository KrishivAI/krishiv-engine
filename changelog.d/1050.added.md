Krishiv for JavaScript and TypeScript, embedded: `Session.builder().getOrCreate()` in the npm package `krishiv` runs queries in-process (engine package `@krishiv/engine-<platform>`), streams results as Arrow batches, cancels on an `AbortSignal` and reports failures as `KrishivError` with the Spark error class and SQLSTATE. Every wheel, CLI binary, npm engine package and the container image now carries a third-party notices file: each third-party crate linked into it, with its license and notice texts.
