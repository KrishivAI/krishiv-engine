The CSV and JSON data sources read and write `TIME` columns with Spark 4.3.0's `timeFormat`, and, under the Spark 4.3
profile, infer `TIME` when `spark.sql.timeType.enabled` is on (Spark 4.2 infers `TIMESTAMP`; new
`krishiv.io.text.inferTime`). A `TIME` read keeps nine fraction digits under the Spark 4.3 profile and six
under 4.2 (a `timeFormat` pattern keeps every digit it reads, as Spark 4.2 does), set by the new
`krishiv.io.text.timeNanos`. `TIME` functions and casts or comparisons of collated strings report the same
result nullability as Spark.
