A permanent view's `DEFAULT COLLATION` is honoured: the string literals and plain string casts of its query take it (named `'a' collate C`, as Spark does), `ALTER VIEW .. AS` keeps it, and the reader's own literals are unaffected. Temporary views take it the same way; ICU collation names are still refused. `view-with-default-collation` (Spark 4.3.0) passes 99 of 120 statements, from 48.

A table's `DEFAULT COLLATION` is honoured: its string columns that name no `COLLATE` (also inside arrays, maps and structs) take it, an explicit `COLLATE` is kept, and `SHOW CREATE TABLE` prints it. The `OBJECT_LEVEL_COLLATIONS` refusal is gone. `show-create-table` (Spark 4.3.0) passes 50 of 50, from 47.
