`DESCRIBE FUNCTION [EXTENDED]` of a SQL function (`CREATE FUNCTION ... RETURN ...`) prints the rows Spark prints: its type, inputs, return type and, with `EXTENDED`, its comment, determinism, data access, captured configuration, creation time and body.
`spark.catalog.listTables` and `listFunctions` with a nested database name (`a.b.c`) refuse it with `NESTED_DATABASE_UNSUPPORTED_BY_V1_SESSION_CATALOG`, as Spark does.
