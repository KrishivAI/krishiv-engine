# krishiv-mcp

An internal crate of [Krishiv](https://krishiv.ai), a Spark alternative in Rust: Spark SQL and DataFrames without the JVM.
It is published only because other Krishiv crates depend on it. To run the MCP server use the
[`krishiv-cli`](https://crates.io/crates/krishiv-cli) package (`krishiv mcp`, behind its `mcp` feature); for the
engine use [`krishiv`](https://crates.io/crates/krishiv). This crate's API is not stable and can change in any release.
