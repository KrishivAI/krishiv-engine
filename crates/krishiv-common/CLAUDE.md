# krishiv-common

**Layer:** L0 (may depend only on crates in L0 or lower; `cargo xtask layering`).  
**Real code arrives:** P0 (registries exist); grows in every phase.

## Purpose
Shared foundation: Spark error classes + SQLSTATE registry (generated by `build.rs` from the vendored Spark 4.2.0 `spark-error-conditions.json` + `krishiv-error-classes.json`; refresh with `python3 tests/scripts/gen_error_classes.py`), typed config registry (`krishiv.*`, `krishiv.experimental.*`), tracing setup.

## Invariants
- No dependencies on other krishiv crates.
- Error classes mirror Spark's `error-conditions.json`; names/SQLSTATEs are API (deprecation cycle before removal).
- Config keys are typed and registered here; `cargo xtask docs-config` / `docs-errors` regenerate docs.
- Secrets are typed (`secret`, ADR 0038): `OptionValue::from_user` is the one classifier; no `Display`/`Debug`
  of a secret type prints plaintext; `redact` is only for untyped free text, never for options.
- Experimental behaviour is gated by `krishiv.experimental.*`, never by Cargo features.
- `#![forbid(unsafe_code)]`.
- No `unwrap`/`expect`/`panic` in library code; errors carry a Spark error class + SQLSTATE.
