# krishiv-cli

The `krishiv` command-line binary of [Krishiv](https://krishiv.ai), a Spark alternative in Rust: Spark SQL and DataFrames
without the JVM. Install it with `cargo install krishiv-cli`, or use the prebuilt binaries from the
[releases page](https://github.com/KrishivAI/krishiv-engine/releases). To use the engine from Rust code, depend on the
[`krishiv`](https://crates.io/crates/krishiv) crate instead.
