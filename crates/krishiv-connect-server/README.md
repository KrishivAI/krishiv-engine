# krishiv-connect-server

An internal crate of [Krishiv](https://krishiv.ai), a Spark alternative in Rust: Spark SQL and DataFrames without the JVM.
It is published only because other Krishiv crates depend on it. Use the [`krishiv`](https://crates.io/crates/krishiv)
crate instead; this crate's API is not stable and can change in any release.
